## Запуск

```bash
npm install
npm run dev
```

Изначально используется мок данные, поэтому backend для запуска не нужен

```env
USE_MOCK=true
```

Для подключения backend:

```env
API_URL=https://.../api/v1
USE_MOCK=false
```

В mock режиме для входа:

```text
login: Artem
password: Artem
```
